# 말랑이의 공부 숲

초등 1~3학년이 국어·영어·산수를 놀면서 익히는 아이패드용 웹 게임입니다.

- 주소: https://hjkwon1234.github.io/mallang-forest/
- 아이패드 사파리에서 주소를 열고 공유 버튼 → "홈 화면에 추가"를 누르면 앱처럼 실행됩니다.

## 구성
- 학년 3개 × 과목 3개, 모두 88단계 (교과 순서대로 배열, 과목마다 학년을 따로 선택)
  - 국어: 따라 쓰기, 낱말, 문장 만들기, 문장 베껴 쓰기, 맞춤법, 높임말, 속담, 짧은 글 읽기
  - 영어: 알파벳, 따라 쓰기, 낱말 철자, 문장, 질문과 대답
  - 산수: 수 세기, 가르기와 모으기, 덧셈·뺄셈(세 자리까지), 곱셈·나눗셈, 시계, 모양, 길이·들이·무게, 분수, 이야기 문제
- 틀린 문제는 다음 날부터 "틀린 문제 복습"에 다시 나오고, 세 번 연속 맞히면 졸업
- 읽어 주는 그림 동화 3편 (각 7쪽)
- 정답마다 당근 1개, 당근을 모아 토끼 친구 20마리 수집
- 공부 다이어리(달력, 날짜별 기록, 오늘 기분)

## 기록 저장
- 별·다이어리·토끼 기록은 이 게임을 연 기기의 브라우저에만 저장됩니다. 서버로 보내지 않습니다.
- 다이어리 화면의 "기록 백업 · 가져오기"로 기록을 글자로 복사해 보관하거나 다른 기기로 옮길 수 있습니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (화면, 문제, 그림이 한 파일에 들어 있음) |
| `sw.js` | 오프라인 실행. 온라인이면 새 버전을 먼저 받고, 오프라인이면 저장본으로 실행 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘과 앱 이름 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내게 하는 표시 |

## 업데이트
`main` 브랜치에 올리면 GitHub Pages가 1~2분 안에 반영합니다. 아이패드는 인터넷에 연결된 상태로 다시 열면 새 버전을 받습니다.
